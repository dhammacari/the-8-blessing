# the-8-blessing
# ☸️ พุทธชัยมงคล ๘ (The Buddha's 8 Victories)
**Interactive Storytelling Platform for Spiritual Reflection**

โปรเจกต์ Web App ขนาดเล็กที่นำเสนอ "พุทธชัยมงคลคาถา" (พาหุงมหากา) ในรูปแบบใหม่ เน้นการเล่าเรื่อง (Storytelling) และการโต้ตอบที่เรียบง่าย เพื่อให้ผู้ใช้งานเข้าถึงความหมายของชัยชนะทั้ง 8 ประการของพระพุทธองค์ได้อย่างลึกซึ้ง

---

## ✨ จุดเด่นของโปรเจกต์ (Key Features)
- **Minimalist Design:** ใช้ UI ที่สะอาดตา เน้นการอ่านและทำสมาธิ
- **Interactive Progression:** ค่อยๆ ปลดล็อกเนื้อหาทีละบท เพื่อสร้างประสบการณ์การเรียนรู้แบบเป็นลำดับขั้นตอน
- **Deep Storytelling:** โดยเฉพาะบทที่ 8 (พกาพรหม) ที่ใช้กุศโลบายเรื่อง "การซ่อนแอบ" มาอธิบายเรื่องอนัตตาและปัญญา
- **Responsive:** รองรับการใช้งานทั้งบนมือถือและคอมพิวเตอร์
